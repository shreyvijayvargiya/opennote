# RowTabs explainer: narration

**s00**  Meet RowTabs. A free, open source Airtable alternative that lives entirely in your browser. Editable tables, sorting, filters, an AI assistant, and a hundred ready-made templates. No account, no server, and it works offline.

**s01**  Start from the gallery. A hundred ready-made tables for CRMs, leads, pipelines, digital products, e-commerce, and more, grouped by category. Search is fuzzy, so typing table for leads WhatsApp finds exactly the table you mean. Add it, and you get the right columns and sample rows to edit.

**s02**  Every cell is editable. Click a status chip to rename it or pick a new color. Choose dates from a calendar, and add bold, italic, or links to text. Add a column and pick from sixteen types, like ratings, sliders, phone numbers, files, avatars, and syntax highlighted code with a language dropdown.

**s03**  Click any header to sort. Search every column at once, stack filters like value greater than ten thousand, and drag rows and columns to reorder them. Select all with one click to delete rows, or send them to the AI.

**s04**  Tables can live inside tables. Add a table link column, search for any table, or create a new linked table right from the cell. In the sidebar, drag a table into a folder or another table, and give each one its own icon.

**s05**  Bring your own data. Drop in a CSV, Excel, JSON, or Markdown file, review the column types that were detected, and create the table. Everything is imported locally in your browser.

**s06**  Export in one click. Copy the table as Markdown, or download a PDF, CSV, HTML, Markdown, JSON, or SQL file. Or view the table as SQL, React code, or JSON, and copy it straight into your project.

**s07**  Every open table gets a tab. Split view puts two tables side by side, with a divider you can drag to resize.

**s08**  The AI assistant works on your tables. Press command L, add your own OpenRouter key, and ask in plain English. It adds rows, edits cells, and creates whole tables, and every change comes with Keep and Undo. Deleting a table always asks you first.

**s09**  Press command K to search your tables, add gallery examples, ask the assistant, or open the M C P settings. A getting started page documents every feature, and ten color themes, in light and dark, make it yours.

**s10**  Everything is stored in your browser with IndexedDB. Private, fast, and free. There are sensible limits to keep it quick: two hundred tables, two thousand rows, and forty columns per table. Export any time.

**s11**  RowTabs is open source and free. Star it, fork it, and build your own tables. Find it on GitHub at shrey vijay vargiya slash rowtabs.
